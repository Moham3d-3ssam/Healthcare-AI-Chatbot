# 🏥 

An AI-powered healthcare chatbot built with **Python**, **Transformers (T5)**, and **Gradio** to provide fast, natural-language health-related responses through a clean chat interface.

## Live Demo

Try it here: **https://huggingface.co/spaces/Moham3d-3saam/healthcare-chatbot**

## ✨ Highlights

- Interactive web chat interface with Gradio  
- Transformer-based response generation (T5)  
- Streaming reply experience for smoother conversations  
- Ready-to-deploy structure with saved tokenizer/model files  

## 🧰 Tech Stack

- Python
- Gradio
- Hugging Face Transformers
- PyTorch

## ⚙️ Run Locally

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   python app/app.py
   ```
